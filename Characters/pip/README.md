# Pip — motion study

Original otter artwork generated through ChatGPT in Brave using the original
Pip image as the reference for each clip. The requested model was GPT Image 2.5;
the UI did not expose the actual model identifier. This design is awaiting user
feedback and is not a finalized collection character.

- Six complete side-facing idle/blink poses from [the matching idle study](../../artwork/pip/idle-side/).
- Eight right-facing gait poses from [the walk refinement](../../artwork/pip/walk-refinement/).
- Shared 256×320 canvas and fixed hood hotspot `(128,48)`.
- Explicit mirrored leftward study; no baked cursor, generic eyes or tether.

Pip retains its facing direction on stopping and under Reduced Motion. Foot
contact, leg separation, turns and settling still need further animation work.
Use size and stride controls in the studio; import/export preserves all frames.
Asset hashes and runtime limitations are in the [review](../../artwork/pip/walk-refinement/review.json).
